## HC 物联网系统

HC物联网系统专注于小区和园区内的设备管理，智能化控制，包括 门禁 道闸 考勤机 充电桩等

## 如何体验

演示环境：http://iot.homecommunity.cn

本机环境：http://localhost:3002
